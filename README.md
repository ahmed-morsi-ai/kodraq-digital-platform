# Kodraq Digital Operating Platform 🚀

> **A Unified Ecosystem for Training, Talent Discovery, and AI-Driven B2B Services.**

## 📖 Overview

Kodraq Digital is not just a Learning Management System (LMS). It is a comprehensive **Company Operating Platform**. The system seamlessly integrates four core domains:

- **Academy:** Paid training, AI-assisted learning (RAG), and strict assessment pipelines.
- **Workforce:** Intelligent task orchestration and an AI Copilot for employees.
- **Client Portal:** B2B project management, quoting, and delivery tracking.
- **Company OS:** Administrative intelligence, profitability analytics, and billing.

## 🛠 Tech Stack

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, Celery, Redis.
- **Frontend:** React, Vite, TypeScript, Tailwind CSS v4.
- **Infrastructure:** Docker, Cloudflare R2 (Storage), OpenAI (AI Gateway).
- **Quality Assurance:** Pytest (100% Pass Rate Policy), Ruff, Oxlint.

## 🚦 Current Roadmap Status

- ✅ **Phase 1-4:** Foundation, Core Domain, Frontend Platform, Student Learning Experience.
- ⏳ **Phase 5 (In Progress):** Training Intelligence & Assessments.
  - ✅ EPIC 5.1: Assignment Domain
  - ✅ EPIC 5.2: Submission System & Rework Workflow
  - ⏳ EPIC 5.3: Assessments / Quizzes (Database modeled)

## 🛡 Architectural Principles

1. **No Terminal Evidence = No Completion:** All commits are backed by 100% passing test suites and strict linting.
2. **Deterministic AI:** AI assists and orchestrates but never bypasses human authorization or RBAC.
3. **Track-Scoped Knowledge:** Strict isolation for RAG and data access.
